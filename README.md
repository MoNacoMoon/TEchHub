# TechHub • Образовательная веб-платформа

Современная образовательная платформа для организации учебного процесса в колледже/вузе с контролем усвоения знаний, интерактивным тестированием, **алгоритмом последовательного открытия лекций**, электронным журналом и инвайт-системой регистрации.

---

## 🌐 Архитектура и стек технологий

* **Бэкенд:** ASP.NET Core (.NET 10), C#, Entity Framework Core
* **База данных:** SQLite (WAL-режим, оптимизация параллельного доступа, поддержка постоянных дисков `/data` в облаке)
* **Почтовый шлюз:** MailKit / MimeKit (реальная отправка кодов подтверждения через Gmail SMTP)
* **Фронтенд:** Razor Pages (MVC), Bootstrap 5, Bootstrap Icons, адаптивный CSS
* **Темы оформления:** Светлая и Тёмная темы с динамическим переключением логотипов и SVG-иконок (🌙 / ☀️)
* **Безопасность:** Cookie Authentication, Anti-Forgery Tokens (CSRF), Rate Limiting, Хеширование паролей (PBKDF2/Identity), Content Security Policy (CSP)
* **Контейнеризация и облако:** Dockerfile (многоэтапная сборка), `amvera.yml` для хостинга **Amvera Cloud**

## 🔑 Модель регистрации и доступа

В системе нет фиктивных пользователей или открытых гостевых входов:
1. **Главный Администратор (`Admin`):**
   * Регистрируется по уникальному мастер-инвайту:
     `http://localhost:5000/Account/RegisterAdmin?code=ADMIN-TECHHUB-2026-X7K9`
   * Обладает полным доступом к системе и генерирует инвайт-ссылки для преподавателей в разделе «Инвайты».
2. **Преподаватели (`Teacher`):**
   * Регистрируются исключительно по персональным инвайт-ссылкам от Администратора:
     `/Account/RegisterStaff?code=TEACH-TECHHUB-XXXXXX`
   * После подтверждения почты получают права на создание дисциплин, лекций, тестов и ведение журнала.
3. **Студенты (`Student`):**
   * Регистрируются по инвайт-кодам своих учебных групп (1–4 курс, группы 111–415).
   * Подтверждают email 6-значным проверочным кодом и получают доступ к закрепленным дисциплинам.

## ☁️ Развертывание в Amvera Cloud

Проект полностью настроен для развертывания на платформе [Amvera Cloud](https://cloud.amvera.ru/):

1. **Файлы конфигурации в репозитории:**
   * `Dockerfile` — многоэтапная сборка на базе `mcr.microsoft.com/dotnet/sdk:10.0` и запуск на `aspnet:10.0`.
   * `amvera.yml` — конфигурация порта (80) и точки монтирования постоянного диска (`persistenceMount: /data`).
2. **Постоянное хранение данных:**
   * База данных SQLite автоматически сохраняется в постоянном разделе `/data/educabinet.db`, благодаря чему все данные пользователей, оценки и материалы сохраняются при перезапусках контейнера.
3. **Команды для развертывания через Git:**
   ```bash
   git remote add amvera https://git.amvera.ru/<ваше-имя>/<имя-проекта>
   git push amvera main
   ```

## 🚀 Локальный запуск

### Вариант 1. Через скрипт
```cmd
run.bat
```
Сервер запустится на адресе: `http://localhost:5000`

### Вариант 2. Через .NET CLI
```bash
dotnet build EduCabinet.sln
dotnet run --project EduCabinet.Web --urls "http://localhost:5000"
```

### Запуск тестов
```bash
dotnet test EduCabinet.sln
```
Все 12 модульных тестов покрывают валидацию инвайтов, аутентификацию, алгоритм последовательного доступа и расчет оценок.
